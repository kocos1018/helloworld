# 전사 전투 시험 실행 안내

## PowerShell·Git 없이 실행

1. 이 구현 브랜치를 Code → Download ZIP으로 받는다.
2. 기존에 작업한 폴더와 다른 새 폴더에 압축을 푼다. 기존 파일은 덮어쓰지 않는다.
3. Godot 프로젝트 목록에서 가져오기 → 압축 푼 폴더의 project.godot를 선택한다.
4. 편집기 오른쪽 위 ▶ 또는 F5로 실행한다. 스크립트를 붙여넣거나 씬을 새로 만들 필요가 없다.

## 조작

- WASD 이동, 마우스 조준, 왼쪽 버튼을 누르면 검 반복 공격.
- Space 회피: 이동 방향, 이동 입력이 없으면 조준 방향.
- 적의 노란 부채꼴은 공격 예고다. 예고 뒤 범위 밖으로 나가거나 무적으로 회피한다.
- R은 전체 재시작. Esc는 일시정지. 창 포커스를 잃으면 자동으로 멈추고 Esc로 재개한다.
- 적 세 마리를 쓰러뜨리면 완료 화면, 체력이 0이면 사망 화면. 버튼 또는 R로 다시 시작한다.

## 구현 범위와 기획 대응

전사 하나, 고정 시험 공간, 추격형 적 3마리, 기본 공격·회피·피격 무적·체력·사망·재시작을 구현했다. 기본 공격 20피해/0.5초/반경32/100도, 적60HP·12피해·0.4초예고, 회피72거리/0.16초/0.12초무적/1초쿨타임을 적용했다. 피격 무적은 0.5초다.

E/Q·게이지·전직·보상·다른 직업·보스는 아직 없다. 첫 완성본의 직업 수를 줄인 결정이 아니다. 이 시험에서는 R로 전사부터 재시작하며 최종 직업 선택 화면은 추후 구현한다. 조작은 임시 도형과 UI로 검증한다.

가설은 이동하면서 조준·검 공격·공격 예고 회피가 연결되는지다. 벽은 사각형 경계 제한이며 장애물·물리 장면·적 분리는 후속이다. 단일 전투 스크립트와 Dictionary 적 데이터는 시험용으로, 다음 단계 전 Player/Enemy 장면과 수치 Resource로 분리한다. 현재 단계에서 이 구조를 완성 게임의 구조로 주장하지 않는다.

## 검증

Linux Godot 4.6.3에서 프로젝트 임포트와 headless 검사 실행. combat_test.gd는 공격 범위·방향·중복 타격·처치, 피격/회피 무적, 회피 거리·경계·쿨타임, 적 예고·회복·빗나감, 일시정지·사망·승리·재시작의 18항목을 검사한다.

실행 명령: godot --headless --path . --script tests/prototype/combat_test.gd

Windows/Godot 4.5.1의 실제 화면·입력·한국어 가독성은 미검증이다. Linux headless 통과를 Windows 플레이 통과로 간주하지 않는다. 게임은 첫 실행에 .godot 캐시를 생성하지만 Git에는 포함하지 않는다. ZIP에는 설치된 Godot로 가져오는 프로젝트가 들어 있으며 독립 실행 EXE는 아직 없다.
