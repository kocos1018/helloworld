# 전직 용사의 구출 작전 — 첫 플레이 완성본 v0.1

## 사지방 PC에서 실행

PowerShell·Git·Node.js·Codex CLI는 필요하지 않다.

1. 구현 브랜치를 Code → Download ZIP으로 받는다.
2. 기존 작업과 다른 새 폴더에 압축을 푼다. 이전 프로젝트 위에 덮어쓰지 않는다.
3. Godot 4.5.1 Standard의 프로젝트 목록에서 가져오기 → 새 폴더의 project.godot를 선택한다.
4. 편집기가 열리면 ▶ 또는 F5를 누른다. 시작 화면에서 직업을 선택한다.

기존 전사 시험 프로젝트를 열면 새 게임이 나오지 않는다. 이름이 ‘전직 용사의 구출 작전’인지 확인한다. 프로젝트 ZIP이며 독립 EXE는 아니다. 공용 PC의 임시 파일 보존 여부는 확인하지 못했다.

## 조작과 목표

| 기능 | 입력 |
| --- | --- |
| 이동·조준 | WASD·마우스 |
| 기본 공격 | 왼쪽 버튼 누르기/유지 |
| 회피 | Space, 이동 입력이 없으면 조준 방향 |
| 일반 스킬·필살기 | E·Q |
| 보스 전 샘 | F 또는 회복 버튼, 선택 사항 |
| 강화 선택 | 숫자 1~3 또는 클릭 |
| 일시정지·설정·모험 포기 | Esc |

전투방 4개를 지나 성문 수문장을 쓰러뜨리면 공주 구출 결말에 도달한다. 두 번째 방 강화 선택 후 전직하며 체력·게이지·강화는 유지한다. 세 번째 방에는 돌진형 엘리트와 일반 적이 함께 나온다. 네 번째 방 강화 뒤 샘을 이용하거나 건너뛸 수 있다.

전사→광전사는 근접·저체력 강화·흡혈, 궁수→사냥꾼은 덫·추가 화살, 마법사→불꽃마법사는 폭발·화상으로 싸운다. 각 직업의 기본 공격과 E/Q가 바뀐다. 필살기는 적에게 피해를 주고 처치하여 충전한다.

사망·승리 후에는 직업을 다시 선택한다. 모험 중간 저장·영구 성장은 없다. 종료 시 진행 포기 안내를 제공하며 음량·화면 설정만 로컬 저장한다.

## 포함한 기능

- 세 출발 직업과 세 전직, 여섯 E/Q 세트, 회피·피격 무적·게이지·저체력 강화·흡혈.
- 덫의 순차 충전/저장3/바닥3, 단일 대상 발동·상태 효과·비재귀 추가 화살.
- 화염탄·범위 폭발·화상 갱신, 필살기 피해의 재충전 방지.
- 일반 적3종, 엘리트, 두 웨이브씩의 방4개, 보스3패턴.
- 공통 강화4종 중 서로 다른3종 제시, 반복 선택·누적, 최대 체력 증가량 회복, 쿨타임 감소의 덫 적용.
- 보스 전 선택적 무료1회 회복, 가득 찬 체력에서 미소비, 사망·구출·재도전.
- 한국어 UI, 직업별 원본 픽셀풍 도형 표현, 공격 예고, 구출 삽화, 합성 배경음·효과음, 음량·전체 화면 설정.

## 원본 표현과 구조

외부 이미지·음원 없이 코드로 만든 픽셀풍 도형과 짧은 합성 음향을 사용한다. 새 외부 에셋 이용 조건은 필요하지 않으며 저장소 MIT 라이선스를 따른다. 최종 전문 아트·음악 제작 완료를 뜻하지 않는다.

src/game/main.gd는 모험·UI·설정, combat.gd는 순수 전투 상태·직업·적, renderer.gd는 그리기, rescue_art.gd는 결말 삽화다. 이전 src/prototype은 전사 시험과 회귀 확인을 위해 보존하며 메인 실행은 src/game/main.tscn이다.

## 검증 결과

Linux의 정확한 Godot 4.5.1에서 다음을 실행했다.

- 프로젝트 임포트·문법 검사.
- tests/game/full_run_test.gd: 전투·직업·상태·예외 155개.
- tests/game/ui_flow_test.gd: 진행·전직·강화·회복·메뉴 96개.
- tests/game/autoplay_test.gd: 정상 체력·공격력·쿨타임·강화·회복을 사용하는 자동 조작으로 세 직업 모두 방1~5와 보스 완료. 적을 강제로 제거하지 않는다.
- Linux 소프트웨어 OpenGL 화면에서 시작·직업 선택·사냥꾼 전투·강화·설정·구출 화면을 캡처해 한국어 가독성과 UI 배치를 확인했다.
- 저장소 문서 영향 검사 함수를 직접 실행하고 git diff --check로 공백을 점검한다. 전체 스튜디오 validate·init·별도 Codex CLI는 실행하지 않는다.

진행 상태 검사의 일부는 적을 강제 제거해 화면 전이를 확인하며 실제 자동 전투 검사와 구분한다. 자동 조작은 사람의 재미·난이도를 검증하지 않는다. 최근 고정 시드 자동 전투 시간은 전사 약231초, 궁수124초, 마법사131초로, 메뉴 선택 시간은 제외한다. 5~10분은 아직 인간 플레이로 검증하지 않은 목표다.

재현: godot --headless --path . --script tests/game/full_run_test.gd, ui_flow_test.gd와 autoplay_test.gd도 같은 방식. Headless에서는 음향 출력을 생략한다.

## 남은 한계

- Windows PC·사지방 장비에서 전체 플레이·성능·음향은 아직 검증하지 않았다. Windows용 독립 EXE를 내보내지 않았다.
- 방 경계 충돌·미리 만든 적 배치 3변형과 바닥 무늬 변화를 사용한다. 내부 기둥·통로 장애물 충돌과 경로 탐색, 여러 실제 지형 레이아웃은 후속이다. 통과 가능한 장식이 장애물처럼 보이지 않게 했다.
- 전사 돌진 베기는 발동 시 선형 범위를 판정하고 이동한다. 전직·회복은 안전한 메뉴에서 이루어지며 샘에 다가가는 별도 탐색 공간은 없다.
- 상점·장비·온라인·패드·키 재설정·영구 성장·20분 확장은 포함하지 않는다.
- 첫 연결 플레이 완성본이며 출시용 QA·최종 밸런스·최종 미술·접근성 인증 완료를 주장하지 않는다.
