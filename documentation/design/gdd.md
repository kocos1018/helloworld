# 게임 기획서 — 전직 용사의 구출 작전（가제）

- 문서 상태: 구현 착수용 기획 기준안 v0.1
- 최초 작성: 2026-11-18 / 위임 설계 정리: 2026-11-19
- 근거: 사용자가 제공한 이전 기획 기록, 후속 합의, “게임 구현 직전까지 알아서 진행” 위임.
- 이번 산출물: 기획 문서. 실제 게임·프로젝트 설정·에셋·빌드 결과물은 아직 없다.
- 첫 완성본: Windows PC, Godot, 도트 탑뷰 실시간 액션, 기본 직업 3개와 각 전직 1개, 한 판 목표 5~10분.

## 1. 결정 상태와 읽는 법

| 표시 | 의미 |
| --- | --- |
| **[확정]** | 사용자가 직접 합의한 방향·규칙. 구현 완료를 뜻하지 않음 |
| **[위임 설계]** | 2026-11-19 위임에 따라 작성자가 선택한 구현 기준. 사용자 개별 승인을 받았다고 주장하지 않음 |
| **[초기값]** | 위임 설계의 수치 초안. 구현 시 출발점으로 사용하고 플레이 검증 후 조정 |
| **[제안]** | 현재 구현 범위에 채택하지 않은 후속 검토안 |

현재 규칙은 1~12장을 기준으로 한다. 13~14장은 이전 점검·합의의 이력을 보존하며, 당시의 제안·미정 표시는 현재 상태와 다를 수 있다. 위임 설계는 기존 확정 사항을 바꾸지 않는 범위에서 기존 후보를 선택하고 빈 규칙을 보완했다.

**경계:** 이번 작업에서 init, 엔진 설치, 게임 구현, 별도 Codex CLI 실행, 에이전트 지침·템플릿·애플리케이션 소스 수정, main 직접 반영·PR 병합은 하지 않는다. 구현은 후속 작업이다.

## 2. 개발 조건·제작 목표·환경

### 2.1 확정된 조건

- 컴퓨터공학과 재학 중이지만 실무·게임 개발 경험이 거의 없는 입문자이며 Codex도 처음 사용한다.
- 1인 개발, 하루 1~2시간. 배우면서 작은 첫 작품을 완성하는 것이 목표다.
- 개발 컴퓨터는 Windows 11. 그림·음악은 다른 AI의 도움을 받을 예정이다.
- 목표 플랫폼은 Windows PC, 엔진은 Godot다. 제작 기한은 정하지 않았다.

### 2.2 위임한 환경 기준

**[위임 설계]** Godot **4.5.1 Standard（.NET 제외）**, GDScript, 2D, Compatibility 렌더러를 기준으로 삼는다. 최신 버전이라는 주장이 아니라 API·문서 기준을 고정하기 위한 선택이다. Windows x86_64에서 로컬 실행·검증하며 C#·외부 엔진 플러그인은 첫 버전에서 사용하지 않는다.

- Windows 로컬 Git 체크아웃과 편집기의 Codex를 연결해 작은 변경을 검토하는 방식으로 계획한다. 클라우드가 유일한 작업 환경이 되게 하지 않는다.
- 이번에는 설치·연결·계정 인증·프로젝트 생성·내보내기 템플릿 설치를 수행하지 않았다.
- **[미정·착수 전 확인]** 실제 로컬 Godot·편집기·Codex 가용성, 해당 버전 실행 및 Windows 내보내기 가능 여부. 부적합하면 호환되는 Godot 4 안정판으로 변경 이유를 문서화한다.
- 설치 파일·내보내기 템플릿은 후속 P0에서 공식 배포본을 확인한다. 이 문서만으로 설치본의 접근성이나 무결성을 검증했다고 간주하지 않는다.
- **[미정·출시 전]** 정식 게임명, 가격, 배포처, 연령 분류, 서명·배포 정책, AI 결과물의 구체적인 권리 증빙. 시험 공간 기획의 추가 사용자 질문으로 삼지 않는다.

## 3. 비전·플레이 목표·범위

### 3.1 핵심 재미

**[확정]** 하데스 계열의 탑뷰 실시간 액션, 도트 그래픽, 용사가 공주를 구하러 가는 판타지다. 다양한 직업을 경험하고 **직업마다 싸우는 방식이 달라지는 것**을 최우선으로 한다. 독특한 직업 발견과 능력 조합은 관심사지만 전투 방식 차이보다 우선하지 않는다.

**[확정]** 첫 완성본은 전사·궁수·마법사와 각각 광전사·사냥꾼·불꽃마법사 전직 하나다. 영구 성장은 첫 버전에서 생략하며 영구 제외가 아니다. 장기적으로 모험 사이의 성장을 도입하고 한 판 약 20분을 지향한다.

**[위임 설계]** 지역은 공주가 갇힌 성으로 향하는 폐성 전초 구역이다. 첫 결말은 수문장 격파 후 공주 구출 글과 이미지 한 장으로 마무리한다. 추가 NPC·대화 선택지·퀘스트는 만들지 않는다. 모든 기본 직업은 출발부터 선택 가능하다. 대상 플레이어는 마우스·키보드로 짧은 액션과 직업 차이를 즐기려는 PC 이용자로 잡고, 초반 적 예고를 읽을 시간을 준다.

### 3.2 첫 완성본 범위

| 항목 | 상태 | 범위 |
| --- | --- | --- |
| 진행 | 확정 | 지역 1개, 전투방 2개 → 전직 → 전투방 2개 → 보스 |
| 분량 | 확정 | 첫 완성본 목표 5~10분. 실제 플레이 시간은 미검증 |
| 일반 적 | 확정 | 근접 추격형·원거리 사격형·느린 돌진형 3종 |
| 엘리트 | 확정 | 느린 돌진형 강화형 1종, 3번 방에서 한 마리와 일반 적이 함께 등장 |
| 보스 | 확정 | 큰 무기를 든 성문 수문장. 넓게 휘두르기·직선 돌진·바닥 내려찍기 |
| 방 구성 | 확정 | 미리 만든 방 조합과 적 배치 변화. 무작위 지형 생성은 사용하지 않음 |
| 보상 | 확정 | 각 전투방 클리어 후 서로 다른 강화 3개 중 하나 선택 |
| 회복 | 확정 | 4번 방 강화 선택 후 보스 전 무료 1회 선택적 회복 |
| 첫 플레이 가능 단계 | 위임 설계 | 전사와 시험 공간부터 공통 전투를 검증. 최종 직업 3개는 유지 |
| 후속으로 이월 | 위임 설계 | 온라인, 복수 지역, 직업 간 능력 혼합, 장비·인벤토리·상점·재화, 제작, 절차적 지형 생성 |
| 첫 버전 생략·보류 | 확정 | 영구 성장·별도 마나 생략, 게임패드 지원 보류 |

**[제안]** 약 20분으로의 확장은 첫 완성본의 재미와 완주 흐름을 확인한 뒤 계획한다. 현재 방·보스 수를 늘리지 않는다. 개발 일정·완료일은 약속하지 않는다.

## 4. 전체 흐름·방·저장

### 4.1 진행 상태

**[위임 설계]** 제목 화면 → 직업 선택 → 방 1 → 강화 → 방 2 → 강화 → 전직 확인 → 방 3 → 강화 → 방 4 → 강화 → 선택적 회복 → 보스 → 구출·결과 화면이다.

- 방 간 진행은 열린 출구 근처에서 F를 눌러 전환한다. 클리어 전 출구는 닫히고 이전 방으로 되돌아가지는 않는다. 강화·전직 완료 전 다음 전투방에 진입하지 못한다.
- 방의 적과 예약된 웨이브가 모두 없어져야 클리어다. 보스 후에는 일반 강화 보상을 추가하지 않는다.
- **[확정]** 두 번째 방의 강화 선택이 전직보다 먼저다. 전직은 전투가 끝난 안전 구간에서 진행한다.
- 전직은 확인 화면에서 설명을 읽고 확정한다. 첫 완성본에서는 전직을 거절하고 이후 전투로 진행하지 않는다.
- 강화·전직·결과 화면은 전투 시간을 멈춘다. 보상 화면을 연 입력이 선택까지 이어지지 않도록 새 입력을 요구한다.
- 클리어 시 적 투사체·지속 공격을 제거하여 보상 중 피해를 받지 않게 한다. 선택한 강화와 체력·게이지는 다음 방으로 이어진다.
- 전직 시 현재·최대 체력, 필살기 게이지, 모험 중 강화는 유지한다. 직업 변경 자체로 최대 체력이 바뀌지 않는다.
- 전직 시 기존 투사체·설치물·시전·화상을 정리하고 일반 스킬을 즉시 사용 가능하게 한다. 사냥꾼은 덫 충전 3회다.
- 방 이동 시 체력·게이지·강화와 남은 쿨타임·덫 충전을 유지한다. 배치 덫은 제거하며 충전을 돌려주지 않는다. 안전 구간에서도 쿨타임·충전은 진행되지만 보상·일시정지 메뉴가 열리면 멈춘다.

### 4.2 방 제작 기준과 초기 배치

**[위임 설계·초기값]** 게임 좌표 1단위는 논리 픽셀 1개다. 논리 화면 640×360, 타일 16×16, 방 외곽 576×288. 카메라는 방 중심에 고정한다. 방별 레이아웃은 개방형·중앙 기둥형·양쪽 통로형의 3개를 재사용한다. 보스는 개방형을 고정 사용한다.

| 방 | 웨이브 1 | 웨이브 2 | 목표 역할 |
| --- | --- | --- | --- |
| 1 | 추격 4 | 추격 4 + 사격 4 | 이동·기본 공격·회피 학습 |
| 2 | 추격 3 + 사격 2 | 추격 3 + 사격 2 + 돌진 2 | 돌진 예고 대응 후 전직 |
| 3 | 엘리트 1 + 추격 2 + 사격 1 | 추격 2 + 사격 1 | 새 직업 능력과 우선 처치 대상 판단 |
| 4 | 추격 4 + 사격 2 + 돌진 2 | 추격 4 + 사격 2 + 돌진 2 | 혼합 전투 후 보스 준비 |
| 보스 | 수문장 1 | 없음 | 패턴 3개 대응. 일반 적 소환 없음 |

- 각 방은 후보 레이아웃과 해당 레이아웃의 검증된 배치 묶음을 뽑는다. 적 종류·수는 표대로 유지하고 좌표 묶음만 달라진다.
- 플레이어 입구 주변 64픽셀 안에는 적을 배치하지 않는다. 벽·오브젝트와 겹치는 배치를 금지한다.
- 방 진입 후 1초, 이전 웨이브 전멸 후 1초의 바닥 예고 뒤 적을 활성화한다. 엘리트와 동반 적은 같은 웨이브다.
- 안전한 후보가 없으면 레이아웃의 고정 배치로 돌아간다. 출구까지의 길과 모든 적 위치는 연결되어 있어야 한다.
- 아직 방 에셋·좌표 묶음을 제작하거나 5~10분을 검증한 것은 아니다. 너무 짧으면 공격 템포를 억지로 늦추기보다 배치·적 생존 시간·이동 시간을 측정해 조정한다.

### 4.3 사망·중도 종료·결과

**[확정]** 사망 시 이번 모험의 직업 선택·전직·강화를 초기화하고 출발부터 직업을 다시 선택한다.

**[위임 설계]** 현재 체력 0 이하이면 사망 처리한다. 사망·구출 화면에 걸린 시간, 처치 수, 직업·전직을 표시하고 ‘직업 다시 선택’과 ‘제목으로’를 제공한다. 승리·사망 모두 다음 모험은 체력 100, 게이지 0, 강화 0으로 시작한다.

- 첫 버전에는 모험 저장·이어하기가 없다. ‘제목으로’·앱 종료 시 진행 포기 안내를 표시한다. 강제 종료·크래시 후에도 이어하지 못한다.
- 음량·화면 설정만 로컬 저장한다. 영구 능력치·해금·재화는 저장하지 않는다.
- 동시 피해에서 플레이어와 보스가 모두 사망하면 사망을 우선한다. 이미 사망한 대상에게 후속 이벤트·보상을 중복 처리하지 않는다.

## 5. 입력·공통 전투 규칙

### 5.1 조작

| 기능 | 상태 | 입력 |
| --- | --- | --- |
| 이동 | 확정 | WASD, 대각선 속도 정규화 |
| 조준 | 확정 | 마우스 |
| 기본 공격 | 위임 설계 | 마우스 왼쪽 버튼. 누르고 있으면 공격 간격에 맞춰 반복 |
| 회피 | 확정 | 스페이스 |
| 일반 스킬·필살기 | 위임 설계 | E·Q, 누를 때 한 번 발동 |
| 상호작용 | 위임 설계 | F |
| 일시정지 | 위임 설계 | Esc. 포커스를 잃어도 자동 일시정지 |
| 메뉴 | 위임 설계 | 마우스 또는 방향키·Enter. 전투 입력과 분리 |

플레이어 중심에 커서를 겹치면 마지막 유효 조준 방향을 유지한다. 입력을 막는 메뉴에서 공격·회피가 새지 않는다. 초기 키 변경 기능은 후속으로 미루고 조작표를 항상 확인할 수 있게 한다.

### 5.2 이동·회피·피격

**[초기값]** 모든 직업의 기본 최대 체력 100, 이동속도 110픽셀/초, 충돌 반지름 6픽셀. 기본 접촉만으로는 피해를 주지 않으며 적의 공격 판정으로만 피해를 받는다.

**[확정]** 회피는 이동 입력 방향으로, 입력이 없으면 마우스로 바라보는 방향으로 짧게 대시한다. 짧은 무적과 쿨타임이 있다.

**[위임 설계·초기값]** 회피 거리 72픽셀, 이동 0.16초, 시작 후 0.12초 무적, 시작부터 쿨타임 1초. 벽에서 멈추고 적 몸체는 통과한다. 기본 공격·일반 스킬의 시전과 필살기 채널링을 회피로 취소할 수 있지만 이미 소비한 자원은 돌려주지 않는다. 지면 지속 효과·분노 버프는 취소하지 않는다.

- 피해를 받은 뒤 0.5초 피격 무적을 준다. 무적 중 후속 피해는 0이며 흡혈·게이지 충전 근거가 되지 않는다.
- 대시 외 이동 스킬에는 별도 무적을 주지 않는다. 보스·적도 공격 예고만으로 무적이 되지 않는다.
- 회피가 같은 프레임의 공격 입력보다 우선한다. 동시 일반 스킬·필살기는 필살기 우선. 죽은 상태·메뉴에서는 모두 금지한다.
- 회피가 없으면 필살기 → 일반 스킬 → 기본 공격 순으로 같은 프레임의 입력을 처리한다. 재사용 불가한 상위 입력이 다른 유효 입력을 삼키지는 않는다.
- 기본 공격 외 표에 시전 시간이 없는 즉발 스킬은 0.20초 동작 중 0.10초에 발사·판정하며, 피의 격노는 0.15초 동작 후 6초간 적용한다. 덫 설치도 동작 후 준비 시간이 시작된다.
- 시전 중 기본 공격은 멈추며, 기본 공격 이외 스킬끼리 겹쳐 시전하지 않는다. 일반 이동은 허용하되 광선 채널링 때만 멈춘다.
- 일반 공격·직선 투사체는 벽에 막힌다. 범위 공격은 중심과 대상 사이가 벽으로 차단되면 맞지 않는다. 적·플레이어 간 아군 피해는 없다.
- 치명타·방어력·원소 저항·확률 회피는 첫 버전에 넣지 않는다. 피해·체력은 실수로 계산하고 HUD는 현재 체력을 올림 표시한다.
- 기본 공격은 공격 한 번당 같은 적에게 한 번만 명중한다. 예외는 명시된 지속·다단 공격의 별도 틱이다.

### 5.3 실제 피해·처치·필살기

**[위임 설계]** 실제 피해는 방어 처리 후 대상에게서 실제로 줄어든 체력이며 남은 체력을 넘는 초과 피해를 제외한다. 화상·추가 화살·덫도 피해 출처를 기록한다. 사망 전환은 한 번이며 마지막 유효 피해의 소유자에게 처치를 부여한다.

**[확정]** 적 피해로 필살기를 충전하며 처치 시 추가 충전한다. 별도 마나는 없다.

**[위임 설계·초기값]** 게이지 최대 100, 출발 0, 필살기 사용 시 100 전부 소비. 실제 피해 1당 0.05, 처치당 3을 충전한다. 피격·자해·회복으로는 충전하지 않는다.

- 기본 공격·일반 스킬·화상·추가 화살은 같은 피해량 기준을 쓴다.
- 필살기 자체의 피해와 그 필살기가 남긴 화상은 충전하지 않는다. 필살기 효과가 지속되는 동안에는 다른 공격의 피해·처치 보너스도 충전하지 않는다. 효과가 끝나면 일반 출처만 다시 충전한다.
- 짧은 단발 필살기는 시전 시작~동작 종료, 지면 필살기는 마지막 틱 종료, 피의 격노는 6초 동안 충전을 잠근다.
- 과도한 다중 대상 충전을 막기 위해 충전 예산 최대 10, 초당 10 재생의 토큰 예산을 사용한다. 출발 예산 10. 피해·처치 보너스 합계는 남은 예산까지만 충전하며 게이지 100을 넘지 않는다.
- 게이지 부족·쿨타임 중·유효하지 않은 조준이면 발동하지 않고 자원·충전을 소비하지 않는다. 필살기 2회분 저장은 없다.
- 아직 계산 방식·상한이 재미를 보장한다는 증거는 없다. 직업별 실제 충전 속도를 비교하는 것이 필수 검증이다.

### 6.4 광전사 저체력 강화·흡혈

**[위임 설계·초기값]** 현재 체력 비율을 h, 강화 계수를 b = clamp((0.60 - h) / 0.40, 0, 1)로 둔다. 체력 60% 이상 b=0, 20% 이하 b=1, 사이에서는 연속적으로 변한다. 임계점의 켜짐·꺼짐 대신 연속 곡선을 쓴다.

- 피해 배율 = 1 + 0.15×공격력 강화 횟수 + 0.50×b. 모든 광전사 피해에 적용한다.
- 기본 공격 빈도 배율 = 1 + 0.10×공격속도 강화 횟수 + 0.35×b. 간격은 기본 간격을 이 배율로 나눈다.
- 피의 격노 동안 b=1을 사용하되 실제 체력은 유지한다. 중복 발동은 게이지 구조상 불가능하며 새 중첩 버프를 만들지 않는다.
- 흡혈은 광전사 **기본 공격의 실제 피해 3%**만 적용한다. 도약·필살기·환경 피해에는 적용하지 않는다.
- 회복 예산 최대 2HP, 초당 2HP 재생, 출발 예산 2HP로 제한한다. 다수 적·다단 이벤트의 회복 합계는 남은 예산과 잃은 체력 이내다.
- 예산은 실제 회복한 양만 차감하며 최대 체력을 넘는 회복은 버린다. 공격별 피해는 타격 직전 체력 기준 b로 정하고 해당 피해 후 흡혈한다.
- 위험: 흡혈과 공격 강화로 저체력이 자동 안전해지는지, 회복 중 조작 감각이 급변하는지 아직 검증하지 않았다. 위험이 사라지면 흡혈·회복 예산부터 조정하고 핵심 저체력 콘셉트는 유지한다.

### 6.5 사냥꾼 덫·추가 화살

**[확정]** 시간에 따라 설치 횟수가 1회씩 충전되고 최대 3회 저장한다. 사용 시 1회 소비하여 덫 하나를 설치한다. 바닥 덫도 최대 3개이며 네 번째 설치 시 가장 오래된 것을 제거한다. 전직 시 3회 충전. 덫 효과 중 기본 공격 명중마다 같은 적에게 추가 화살 한 발을 발사하며 추가 화살은 재귀 발동하지 않는다.

**[위임 설계·초기값]**

- 덫은 조준 방향 96픽셀 이내 바닥에 설치하며 벽·통행 불가 지점은 설치 실패로 충전을 소비하지 않는다.
- 하나의 충전 타이머가 6초마다 1회씩 순차 충전한다. 부족한 세 충전을 동시에 돌리지 않는다. 3회가 되면 타이머를 멈추고 잉여 시간을 저장하지 않는다.
- 설치 후 0.25초 준비, 유지 30초, 감지 반경 12. 첫 진입 적 하나에게 피해 10을 주고 즉시 바닥에서 제거되며 효과는 적에게 남는다.
- 동시 진입은 가장 가까운 적, 동률은 고정 생성 순번으로 한 명만 선택한다. 발동·만료·오래된 덫 제거는 충전을 돌려주지 않는다.
- 일반 적은 2초 이동 불가, 엘리트는 1초 이동 불가, 보스는 2초 이동속도 30% 감소. 효과는 중첩하지 않고 재적중 시 남은 시간을 새 지속시간으로 갱신한다.
- 이동 불가인 적도 사거리 안에서 일반 공격·사격은 가능하다. 일반·엘리트의 돌진 중 이동 불가가 적용되면 돌진을 중단하고 0.5초 후 회복한다.
- 보스 돌진은 취소되지 않고 둔화 중 속도만 0.7배가 된다. 정해진 돌진 시간은 유지하여 실제 거리가 줄어든다.
- 추가 화살 피해 9, 속도 420/초, 최대 거리 400. 발사 순간 같은 적의 위치를 향하며 유도하지 않는다. 해당 표적과 벽만 충돌하고 다른 적에게 표적을 바꾸지 않는다.
- 기본 화살 피해 직전 덫 효과가 유효했는지로 발동을 결정한다. 그 타격으로 적이 죽어도 마지막 위치로 한 발을 발사하되 사망 표적에 피해·처치·충전을 다시 만들지 않는다.
- 추가 화살은 빗나갈 수 있다. 기본 공격 출처와 구분해 다른 추가 화살을 만들지 않으며 화살비·덫 피해도 추가 화살을 만들지 않는다.

### 6.6 화상

**[위임 설계·초기값]** 화상은 3초, 0.5초마다 기본 피해 1.5로 총 6틱이다. 같은 플레이어의 화상은 하나만 유지한다.

- 같은 출처 재적용 시 남은 시간을 3초로 갱신하며 다음 틱까지의 진행 시간은 초기화하지 않는다.
- 다른 화상 출처는 배율 적용 후 틱 피해가 큰 것을 채택하고 시간을 갱신한다. 동률이면 기존 출처를 유지한다. 더 약한 출처가 필살기 화상을 일반 공격 출처로 바꿔 충전하게 하지 않는다.
- 필살기 출처 화상은 끝까지 필살기 태그를 유지한다. 기존 화상에 새 출처가 채택되면 새 피해값과 출처를 함께 기록한다.
- 적용 시점의 공격력 배율을 저장하고 이후 버프 변화로 과거 화상 피해가 바뀌지 않는다. 새로 갱신할 때 재계산한다.
- 만료 시각과 마지막 틱이 같으면 마지막 틱을 먼저 처리하고 제거한다. 처치된 적에게는 나머지 틱을 만들지 않는다.
- 사망·방 종료 시 제거한다. 틱별 실제 피해·처치는 한 번만 반영하고 이미 사망한 대상에게 적용하지 않는다.

## 7. 적·엘리트·보스 상세 기준

모든 수치는 **[초기값]**, 행동은 **[위임 설계]**다. 예고 중 마지막 0.2초에는 조준을 고정하고 공격 후 빈틈을 준다. 적끼리 몸이 완전히 겹치지 않게 간단한 분리를 적용하되 복잡한 분대 AI는 만들지 않는다.

| 대상 | 체력·이동속도 | 공격 | 예고·후딜레이·재사용 |
| --- | --- | --- | --- |
| 근접 추격형 | 60HP, 65/초 | 거리 22에서 12피해 단발 | 예고 0.4초, 후딜레이 0.4초, 시작 간격 최소 1.2초 |
| 원거리 사격형 | 50HP, 50/초 | 거리 144~208 유지, 10피해 투사체 140/초, 사거리 320 | 예고 0.6초, 후딜레이 0.3초, 시작 간격 최소 1.8초 |
| 느린 돌진형 | 90HP, 추적 40/초 | 거리 64~192면 직선 144 돌진/0.4초, 18피해 | 예고 0.8초, 후딜레이 0.8초, 시작 간격 최소 3초 |
| 강화 돌진 엘리트 | 240HP, 추적 40/초, 외형 1.5배 | 거리 64~240면 직선 208 돌진/0.5초, 22피해 | 뚜렷한 1초 예고·후딜레이 1초·시작 간격 최소 3.5초 |

- 느린 돌진형과 엘리트는 너무 가까우면 거리를 벌려 돌진을 준비한다. 일반 이동이 막히면 경로를 다시 찾는다.
- 돌진은 벽에서 멈추며 표적 한 번만 피해를 받는다. 사격은 시야가 막히면 발사 대신 위치를 바꾼다.
- 적 밀침·속박은 6장의 공통 규칙을 따른다. 엘리트 추가 보상은 없고 방 클리어 강화가 보상이다.
- 위 표는 이름·미술 완성본을 뜻하지 않는다. 적의 실루엣과 예고 모양을 먼저 구분한다.

### 7.1 성문 수문장

**[확정]** 큰 무기를 든 성문 수문장, 넓게 휘두르기·직선 돌진·바닥 내려찍기 3패턴.

**[위임 설계·초기값]** 체력 2400, 추적 속도 45/초, 일반 적 동반·소환과 추가 페이즈 없음.

| 패턴 | 실행 기준 |
| --- | --- |
| 넓게 휘두르기 | 0.8초 부채꼴 예고 → 전방 160도·반경 72에 24피해 단발 → 1초 빈틈 |
| 직선 돌진 | 1초 직선 바닥 예고 → 224거리/0.7초의 고정 방향 돌진·28피해 → 1.2초 빈틈. 벽에서 멈춤 |
| 바닥 내려찍기 | 1초 원형 예고 → 보스 중심 반경 88에 30피해 단발 → 1.2초 빈틈. 충격파 없음 |

- 휘두르기 → 돌진 → 내려찍기 순서를 반복한다. 패턴 사이 최대 1.5초 추적한 뒤 현재 위치에서 다음 패턴을 시작한다.
- 준비 중 첫 부분은 추적·조준을 갱신하되 마지막 0.2초에는 방향·중심을 고정한다. 판정 후 경고를 제거한다.
- 접촉 피해·연속 몸통 다단 피해는 없다. 회복·버프 등으로 체력이 다시 차는 패턴도 없다.
- 일반·엘리트 돌진과 차이는 부채꼴·원형 공격을 섞고 넓은 바닥 예고와 긴 후딜레이를 제공하는 데 둔다.

## 8. 강화·회복·수치 계산

### 8.1 보상 선택

**[확정]** 전투방마다 서로 다른 강화 3개 중 하나를 고른다. 같은 모험에서 같은 강화가 다시 등장·선택·누적될 수 있다.

**[위임 설계]** 아래 4종을 균등하게 섞어 서로 다른 3종을 뽑는다. 각 강화의 등장 확률은 보상당 3/4, 지난 선택에 따른 가중치는 없다. 네 방으로 총 네 번 선택하므로 각 강화의 가능한 횟수 n은 0~4다. 다시 뽑기·선택 취소·보상 건너뛰기는 없다.

| 강화 | 초기값·계산 |
| --- | --- |
| 공격력 | 선택마다 기본값 대비 +15%, 합산. 모든 플레이어 피해에 적용하되 광전사 저체력 배율과도 합산 |
| 공격속도 | 선택마다 기본 공격 빈도 +10%, 합산. 스킬 쿨타임·화상·필살기 틱에는 미적용 |
| 최대 체력 | 선택마다 +20, 현재 체력도 +20. 현재 체력은 새 최대 체력 이내 |
| 일반 스킬 쿨타임 | 기본 쿨타임·덫 1회 충전 시간을 선택마다 8%씩 단축. 4회면 기본값의 68% |

- **[확정]** 최대 체력 증가량만큼 현재 체력도 회복한다. 예: 40/100 → +20 선택 → 60/120. 전직 자체는 현재·최대 체력을 바꾸지 않는다.
- 쿨타임과 덫 충전 진행률은 강화 전후 유지한다. 예를 들어 6초 중 3초 진행 상태에서 8% 감소를 얻으면 5.52초 중 2.76초 진행으로 바뀐다.
- 예산·최소 체력·게이지 상한과 같은 제한은 피해 배율로 늘어나지 않는다. 필살기 충전 계수와 회피 쿨타임은 이 강화로 변하지 않는다.
- 초기 범위에서는 강화 4회가 자연 상한이므로 상한 도달 항목을 보상에서 제거할 필요가 없다. 다섯 번째 일반 방 보상을 만들지 않는다.
- 광전사 이외의 공격력 배율은 1 + 0.15×공격력 강화 횟수다. 기본 공격 간격은 기본 간격 / (1 + 0.10×공격속도 강화 횟수)로 계산한다. 일반 스킬 쿨타임·덫 충전 시간은 기본값 × (1 - 0.08×해당 강화 횟수)다.
- 기본 공격의 진행 중 간격도 공격속도 변화 전후 진행률을 유지하고, 입력을 누르고 있어도 한 프레임에 지연된 공격을 몰아서 발생시키지 않는다.
- 기본 피해와 배율은 실수로 계산하고 반올림으로 피해 0이 되는 일을 막는다. 강화 UI는 증가 전후의 값을 보여준다.

### 8.2 보스 전 회복

**[확정]** 4번 방 강화 선택 후 오브젝트와 상호작용해 무료로 한 번 이용하며, 원하면 건너뛰고 보스에게 갈 수 있다.

**[위임 설계·초기값]** 회복 오브젝트는 작은 샘, F로 이용한다. 현재 최대 체력의 30%를 회복하되 최대 체력을 넘지 않는다. 체력이 가득 차면 ‘이미 회복되어 있습니다’를 표시하고 이용 횟수를 소비하지 않는다. 사용한 샘은 비활성화하며 방을 드나들어 재사용할 수 없다. 회복은 게이지를 채우지 않는다.

회복량은 고정 비율일 뿐 완전 회복 보장이 아니다. 광전사에게 회복 후 저체력 강화가 줄어듦을 설명하며 자동 사용하지 않는다.

## 9. 화면·미술·음향·접근성

### 9.1 필수 화면

**[위임 설계]**

- 제목: 시작·설정·종료. 직업 선택: 세 직업의 기본 전투 방식과 전직 예고.
- HUD: 현재/최대 체력, 현재 직업, E 쿨타임 또는 덫 충전 수·다음 충전 진행률, Q 게이지, 회피 쿨타임, 방 번호·남은 적 수.
- 강화: 세 카드의 이름·효과·현재 중첩 수·선택 후 값. 숫자키 1~3 또는 클릭.
- 전직: 변경 전후 공격·스킬 설명, 체력·게이지 유지 안내, 확인 버튼.
- 일시정지: 계속·조작표·음량·화면 설정·제목으로. 설정은 모험을 초기화하지 않는다.
- 사망·구출: 간단한 기록과 재시도. 첫 시작에서 화면 위 짧은 조작 안내를 표시하며 별도 튜토리얼 방은 늘리지 않는다.

### 9.2 표현·에셋 준비 목록

**[위임 설계]** 어두운 성 배경과 밝은 플레이어·위험 예고를 대비시킨다. 픽셀 필터는 nearest, 기본 1280×720 창, 640×360 논리 해상도를 정수 배율·레터박스로 표시한다. UI는 화면 바닥 영역에 두어 적 예고를 가리지 않는다.

| 에셋 묶음 | 최소 산출물·재사용 |
| --- | --- |
| 플레이어 | 공통 몸체의 대기·이동·공격·피격/사망, 좌우 2방향과 반전. 검·대형 무기·활·지팡이와 직업색으로 6상태 구분 |
| 적 | 일반 적 3실루엣, 돌진형 확대·테두리의 엘리트 변형, 큰 무기 수문장 1 |
| 환경 | 성 바닥·벽·기둥 타일, 출입구·회복 샘, 레이아웃 3종 |
| 효과 | 베기·돌진 흔적·투사체·덫·화상·폭발·원/직선/부채꼴 예고 |
| UI·결말 | 공통 강화 아이콘 4개, 스킬 구분 아이콘, 구출 이미지 1장과 짧은 한국어 글 |
| 소리 | 공격/명중/피격/회피/덫/화상/예고/보상/승패 효과, 일반 전투·보스 음악 각 1곡 |

구현 초반은 도형·단색 임시 효과로 검증한 뒤 교체한다. 지금 AI 생성·다운로드·바이너리 변경은 하지 않는다. 채택할 때 출처·생성 도구·수정·이용 조건을 에셋 목록에 기록한다. 권리가 불명확한 결과물은 배포용으로 채택하지 않는다.

### 9.3 최소 접근성·설정

- 색만으로 위험을 알리지 않고 형태·외곽선·예고 동작·소리를 함께 사용한다.
- 화면 흔들기는 기본 끔, 효과 플래시는 약하게. 음량은 전체·음악·효과를 나눠 조절한다.
- 한국어 글꼴·줄바꿈·키 표시를 확인한다. 텍스트는 논리 화면에서 최소 12픽셀을 출발점으로 하며 실제 Windows 화면에서 가독성을 검증한다.
- 패드·다국어·키 재설정은 첫 버전 후속 항목이다. 적색만으로 체력·위험을 구분하지 않는다.

- 피해 이벤트: 실행 ID·틱 ID, 가해자·대상 ID, 원본 피해·배율, 능력 출처, 필살기 여부, 기본 공격 여부.
- 모험 기록: 선택 직업·전직, 강화별 0~4 횟수, 방 1~5, 웨이브, HP·게이지, 회복 이용 여부, 시간·처치 수.
- 방 정의: 레이아웃 ID, 입구·출구·유효 배치점, 웨이브별 적 ID와 수, 예고 시간.
- 설정 저장: 스키마 버전, 음량·화면 모드. 모험 데이터를 섞지 않는다.

수치는 Godot Resource 등 엔진 기본 데이터로 분리한다. 별도 DB·서버·모드 시스템·복잡한 이벤트 프레임워크는 도입하지 않는다. 적 탐색은 방 안에서만 수행하며 60Hz 물리를 기준으로 계획한다. 아직 성능 수치·메모리 한도는 측정하지 않았다.

### 11.3 플레이 재미·성능 관문

- 전직 쌍마다 전후 3회 이상 관찰한다. 광전사는 저체력 위험과 공격 기회, 사냥꾼은 덫 위치·집중 사격, 불꽃마법사는 적 무리 상대의 행동 차이를 기록한다.
- 직업별 피해/처치·필살기 첫 사용 시각·회복량·피격 원인·완주 시간을 수동 기록한다. 외부 텔레메트리를 도입하지 않는다.
- 저체력 광전사가 일부러 공격을 맞아도 항상 회복하며 생존하면 실패로 보고 흡혈부터 조정한다.
- 덫을 쓰지 않아도 플레이가 같거나 화상·추가 화살로 필살기 빈도가 현저히 높으면 해당 수치와 규칙을 재검토한다.
- 수문장 공격을 예고만 보고 구분할 수 있어야 한다. 맞을 수밖에 없는 배치·벽 끼임·진행 막힘은 완료를 막는 결함이다.
- 5~10분은 초반 완주 목표다. 세 직업 실제 완주를 측정하기 전 달성했다고 쓰지 않는다.
- 성능 목표는 확인한 Windows 시험 PC에서 보통 전투 60FPS다. 정확한 PC 사양·최악 프레임·적/효과 수를 함께 기록한다. 현재 성능·최소 사양은 미검증이다.

## 14. 후속 합의 기록 — 2026-11-18

아래는 결정 당시의 기록이다. 이후 합의로 바뀐 항목의 현재 상태는 본문의 해당 절과 가장 최근 합의를 기준으로 한다.

- 사용자 답변 1: 약 20분의 한 판을 원하지만 초기 기획에서는 제안한 짧은 구성으로 시작하기로 합의했다. 지역 1개, 전투방 2개 → 전직 → 전투방 2개 → 보스, 첫 완성본 목표 5~10분을 확정으로 반영했다.

### 엘리트 형태 추가 합의 — 2026-11-18

- 사용자는 일반 적의 강화형과 전용 패턴을 가진 별도 적 중 강화형을 선택했다.
- **[확정]** 첫 완성본의 엘리트 1종은 일반 적을 강화한 형태다.
